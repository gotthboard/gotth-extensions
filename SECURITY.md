# Security policy

Do not report vulnerabilities in a public issue. Use GitHub private
vulnerability reporting for the future public distribution repository, or a
private owner-approved channel while that repository is unavailable.

Never include credentials, secret values, private manifests/grants, production
endpoints, or raw product data in a report. Include the affected commit,
protocol/schema version, minimal reproduction, and impact.

This repository is unreleased. No version currently carries a support or
security-maintenance promise.
